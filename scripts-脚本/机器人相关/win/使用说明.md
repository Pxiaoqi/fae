# 一键连接机器人 Wi-Fi（Windows 版）使用说明

给现场同事看的简易说明，不需要懂技术。

## 这个工具干什么

在 Windows 电脑上双击一下，就帮你把机器人连上指定的 Wi-Fi，并自动确认"真的能上网"。
机器人那边不用装任何东西、也不用改设置。

## 用之前确认三件事

1. 电脑是 Windows 10 / 11（系统自带的 ssh 能用）。
2. 电脑已经连上这台机器人：连机器人的热点、或和机器人在同一个网络、或网线直连。
3. 知道机器人的登录密码（默认是 `robot`）。

## 怎么用（照着做就行）

1. 双击 **`一键连接机器人WiFi.cmd`**（只双击这一个文件）。
2. 提示 `password:` 时，输入**机器人登录密码**，按回车（输入时不显示，是正常的）。
3. 屏幕上出现菜单，按数字选：
   - 按 `1`：**知道 Wi-Fi 名字**，直接输入 Wi-Fi 名称和密码。
   - 按 `2`：**不知道名字**，先扫描附近 Wi-Fi，再输入列表中对应的编号。
4. 提示要 Wi-Fi 密码时：
   - 直接**按回车** = 使用默认密码 `AI2Rocks!`
   - 输入 `-` = 这个 Wi-Fi 没有密码（开放网络）
5. 中途可能再提示一次密码（机器人内部提权用），**还是输入机器人登录密码**。
6. 看到绿色的 `Wi-Fi 连接成功` 就完成了，窗口 3 秒后自动关闭。

## 看到这些提示是什么意思

| 屏幕上的提示 | 意思 / 怎么办 |
| --- | --- |
| `连接失败：是否没有连接到设备？` | 电脑没连上机器人。检查电脑的 Wi-Fi/网线，确认连的是这台机器人 |
| `没找到这个 Wi-Fi` | 名字写错了，或离路由器太远。注意机器人多数只支持 2.4G 频段 |
| `密码错误或加密方式不匹配` | Wi-Fi 密码不对，重新跑一次输对密码 |
| `机器人可能没拿到 IP 地址` | Wi-Fi 连上了但上不了网，检查路由器是否正常联网 |
| `找不到 Windows 自带的 OpenSSH` | 电脑缺少 ssh 组件，把窗口内容发给技术同事处理 |
| `sudo 密码不正确` | 机器人登录密码输错了，重新跑一次 |

失败时窗口不会自动关，会停在最后一行，把整屏内容截图发给技术同事即可。

## 几条规矩（避免出错）

- **三个文件必须放在同一个文件夹**，且**不能改名**：
  `一键连接机器人WiFi.cmd`、`robot-wifi.ps1`、`robot-wifi-remote.sh`。
  要搬到别的电脑，就整个文件夹一起复制。
- **只双击 `.cmd`**。双击 `.ps1` 可能被系统拦截或一闪而过。
- **不要把 `robot-wifi-remote.sh` 拷到机器人上**。它在运行时会被自动临时放到机器人 `/tmp`，跑完自动删除，机器人上不留文件。
- **运行中别关窗口、别拔网线、别切电脑的 Wi-Fi**，否则会中断。
- 一次只连一台机器人。给多台机器人操作时，一台跑完再跑下一台。
