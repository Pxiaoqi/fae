# 智魔方点单系统 · 部署与使用手册

> 适用对象：现场操作/维护人员。本手册用大白话讲解，看完就能部署和使用。

## 一、这个系统是干什么的

顾客用手机或平板连上机器人的 WiFi 热点，打开一个网页，就能选饮品下单；机器人收到订单后自动制作，做好后送到取餐位置。

操作人员（比如店长、运维）可以在同一个网页上：

- 查看今天下了哪些单、每单做了多久
- 管理菜单（哪些饮品能点、哪些缺货）
- 给饮品加标签（比如"含酒精""半杯"）
- 删掉误下的订单、一键清空未制作的单

## 二、部署前要准备什么

- 一台机器人（已经装好咖啡/饮品系统和 Docker）
- 一台电脑（第一次部署用，需要能连上机器人）
- 手机或平板（顾客点单用）
- 部署包（一个 zip 文件，由开发人员提供）

## 三、第一次部署步骤

1. 把部署包 zip 拷贝到机器人上（用 U 盘或网络都行）
2. 在机器人上解压，会得到一个文件夹
3. 打开终端，进入这个文件夹
4. 运行下面命令，按提示选择 **1（导入容器内运行）**：

   ```bash
   ./start.sh
   ```

5. 看到"✅ 完成！"和一行网址后，先用电脑浏览器打开试试
6. 手机连上机器人热点，打开同一个网址（通常形如 `http://192.168.55.1:8077`）

【图片：电脑浏览器打开后的首页】

> 第一次启动要读取配置，可能会等十几秒到几十秒，属正常现象。

## 四、以后怎么启动（不用再配置）

第一次部署时，系统会自动记住配置并生成一个"一键启动"脚本。

- **机器人（容器外）再次启动**：在程序文件夹里运行

  ```bash
  ./quickstart.sh
  ```

- **进入容器内启动**：

  ```bash
  cd /opt/coffee-order-ui && ./quickstart.sh
  ```

- 想重新按向导配置一遍：`./start.sh --wizard`
- 只想看端口开没开：`./start.sh --check`

## 五、页面功能讲解（逐个模块）

### 1. 顶部信息区

- **标题**：智魔方点单系统
- **状态灯**：绿色=一切正常；红色=服务或容器连接有问题
- **📋 今日订单**：点开查看今天的订单
- **⛶**：进入纯净点单模式（全屏只显示卡片）
- **⚙ 编辑**：打开管理设置

### 2. 点单卡片区（顾客用的主界面）

- 页面按分类显示饮品：咖啡 / 冰激凌 / 啤酒 / 鸡尾酒。**显示哪个分类由机器人当前配置自动决定**，不需要手动切换
- 每张卡片会显示：
  - 饮品名称
  - **标签**（左上角，如"含酒精""半杯"；含酒精的标签是红色）
  - **提示词**（卡片上的一行小字，如"意式不加水，打出来就是半杯！！！"）
  - **缺货**：该饮品置灰，点不了，点击会弹出提示词
- 顾客点一下卡片就下单，马上会弹出"下单成功"和**取餐码**
- 为了防止误点，同一款饮品 1 秒内重复点击会被拦下

【图片：点单页（正常卡片 + 缺货卡片 + 标签示例）】

### 3. 待制作订单区

- 显示当前还没做完的订单
- 状态：**待制作**（黄色）、**制作中**（蓝色）
- 每笔订单右边有"删除"按钮：只有还没开始做的才能删
- 右上角"一键清除未制作"：清掉所有还没开始做的单

【图片：待制作订单区】

### 4. 今日订单（右侧抽屉）

- 顶部显示今天一共多少笔订单
- 下面按时间倒序列出**每一笔订单**：饮品名、**下单时间**、**制作时间**
- 订单多时可以上下滚动查看
- 制作时间显示"失败"的，表示这单没有正常完成（可能被取消/中断），属正常记录

【图片：今日订单抽屉】

### 5. 编辑弹窗（⚙ 编辑）

编辑弹窗里有两个页签：

**页签一：菜单设置**

- 左侧选分类（咖啡/冰激凌/啤酒/鸡尾酒），打开时默认选中当前页面显示的分类
- 宫格布局：4×2 或 6×2，按展示效果选
- 饮品列表：勾选/取消勾选，决定这个分类里能下单哪些饮品
- 每款饮品行右侧有 **✎** 按钮，点开可单独设置这款饮品

**页签二：制作时长监听**

- 开关：开启后记录每单的制作时长（只有程序在容器内运行时才有）
- 起点/终点规则：告诉程序"从哪个动作开始计时、到哪个动作结束"
  - 模板：备注用，可不填
  - 路径层级：可以点"+ 路径层级"增加，按机器人的实际流程填
  - 节点：实际计时的动作节点名
  - 页面会显示"自动定位"，告诉你程序找到了哪一层
- 改完点"保存规则"立即生效

【图片：编辑弹窗-菜单设置】
【图片：编辑弹窗-制作时长监听】

### 6. 饮品编辑弹窗（点 ✎ 打开）

- **标签**：点"+ 标签"添加，点 × 删除；标签会显示在卡片左上角，含"酒精"字样的显示红色
- **提示词**：会显示在卡片上；下单成功时也会带上这句提示
- **禁止下单**：打开后该饮品变灰、顾客点不了（比如缺货）；这时提示词会作为点击后的提示

【图片：饮品编辑弹窗】

### 7. 纯净点单模式

- 点右上角 ⛶ 进入：全屏只显示饮品卡片，适合放在展示屏/大屏上
- 切换分类：电脑按左右方向键，手机/平板左右滑动
- 退出：按 Esc，或点右下角"退出纯净模式"

## 六、制作时长是怎么算的（简单版）

程序会自动"偷看"机器人的运行日志：

1. 订单开始制作时，机器人会做一个"转身去制作位"的动作
2. 做完送餐时，机器人会做一个"张开夹爪放下饮品"的动作
3. 这两个动作之间的时间，就是这一单的制作时长

这些动作名字在页面"制作时长监听"里可以改，机器人流程变了也不用改程序。

## 七、日常管理

- **改菜单/标签/缺货**：页面 ⚙ 编辑 里改，保存后立即生效
- **看订单记录**：`orders.log`（每笔下单/删除/完成）
- **看制作时长记录**：`order_times.log`
- **备份你的设置**：把 `menu_overrides.json` 存好；换一台机器人时，拷这个文件和 `menu_config.yaml` 过去，大部分设置能直接带过去（机器人饮品编号一致的前提下）
- **机器人重启后**：重新运行 `./quickstart.sh` 即可

## 八、常见问题（排查表）

| 现象 | 原因与解决办法 |
| --- | --- |
| 手机打不开页面 | 确认手机连的是**机器人的热点**；地址要输对（机器人IP:8077）；先用电脑浏览器试一次 |
| 下单了机器人不动 | 机器人主程序没启动，请联系技术人员启动咖啡系统 |
| 订单一直"待制作" | 机器人还没开始做，或主程序没运行 |
| 制作中订单删不掉 | 这是设计好的：开始制作后不允许删除，防止出错 |
| 端口被占用 | 换一个端口重新配置（`./start.sh --wizard`），或找技术人员调整 |
| 机器人重启后页面打不开 | 服务没自启，重新运行 `./quickstart.sh` |
| 卡片标签不显示/不对 | 在 ⚙ 编辑 → ✎ 里检查标签；保存后刷新页面 |
| 制作时长显示"失败" | 该单未正常完成（被取消/中断/删单），正常记录 |

## 九、给维护人员的速查

```bash
# 一键启动（容器外）
./quickstart.sh

# 查看服务状态
curl http://127.0.0.1:8077/api/health

# 进入容器内一键启动
cd /opt/coffee-order-ui && ./quickstart.sh
```

关键文件位置（容器内 `/opt/coffee-order-ui/`）：

- `menu_config.yaml`：菜单与分类配置
- `timing_config.yaml`：制作时长监听配置
- `menu_overrides.json`：页面里改过的设置（标签/缺货/绑定）
- `orders.log` / `order_times.log`：订单与制作时长记录

页面端口默认 **8077**。
